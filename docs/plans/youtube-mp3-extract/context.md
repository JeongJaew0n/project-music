## 결정
- 이전 작업(Soundalike·musickit 등)은 커밋된 적이 없어 지우면 복구할 수 없으므로,
  삭제 대신 저장소 밖 `~/my/Dev/project-music-old-20261114/` 로 옮겼다.
- yt-dlp 를 brew 바이너리가 아니라 파이썬 의존성으로 둔다 — uv 로 버전이 고정되고 함수로 부를 수 있다.
  유튜브가 자주 바뀌므로 깨지면 `uv lock --upgrade-package yt-dlp` 로 올린다.
- 옵션은 yt-dlp 의 CLI 인자를 `yt_dlp.parse_options` 로 바꿔 쓴다 — 썸네일 변환 등 CLI 가 알아서 붙이는 후처리를 직접 재현하지 않으려고.
- mp3 품질은 VBR V0. 유튜브 원본 오디오가 opus 약 130~160kbps 라 그 이상(320k CBR)은 파일만 커진다.
- 새 FeatureGroup `ytmp3/` (최상위 패키지).
