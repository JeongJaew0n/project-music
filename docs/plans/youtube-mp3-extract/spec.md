# spec — 유튜브 링크 → mp3 추출

## 범위
- 유튜브 URL 을 받아 오디오만 내려받아 mp3 로 저장한다.
- 명령줄: `uv run ytmp3 <URL> [<URL> ...] [-o 폴더]`
- 파이썬에서 부를 수 있는 함수 `ytmp3.extract_mp3(url, out_dir)` — 다음 단계(AI 정리)가 이 함수를 쓴다.

## 동작
- 가장 좋은 오디오 스트림을 받아 ffmpeg 로 mp3(LAME VBR V0, 약 245kbps) 변환.
- 제목·업로더 메타데이터와 썸네일(앨범아트)을 mp3 에 넣는다.
- 파일 이름: `<영상 제목>.mp3`. 같은 이름이 이미 있으면 다시 받지 않고 그 경로를 알려준다.
- 재생목록 링크(`&list=`)여도 그 영상 하나만 받는다.
- 저장 폴더 기본값: `~/Downloads`.

## 범위 밖

## 완료 조건
- 단위 시험 통과 (`uv run pytest -q`).
- 실제 유튜브 영상 하나로 mp3 가 만들어지고 ffprobe 로 mp3·길이 확인.
- 잘못된 URL 은 알아볼 수 있는 한국어 오류로 끝나고 종료 코드 1.
