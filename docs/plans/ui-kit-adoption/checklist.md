## ui-kit 0.4 (2026-11-18, 세션마스터 전달 · 사용자 지시 연장)
- [x] `adopt.mjs --from 0.4` 로 0.4.0. 이름 바뀐 것 없음. 손맛 calm(`data-ui-feel="calm"`, 기본값을 드러내 적음).
- [x] 화면 전환 `UI.transition`: 하단바·메뉴바(주소 # 바뀜) → tab, 받은 곡 목록 → 편집기 → forward(나란히 보이는 넓은 화면에서는 전환 없이), 뒤로 → back.
  키트는 행(`data-ui-detail`)·뒤로(`data-ui-back`)를 문서의 click 에서 바로 바꾸므로, 그 전에 `#songs`·뒤로 버튼에서 받아 전환으로 감싸고 전파를 멈춘다.
  받기 카드의 "구간 자르기"는 주소 바꿈까지 forward 하나로(그때의 hashchange 는 건너뜀).
- [x] 화면 자동 점검에 더함: 종류(tab,forward,back,tab), update 한 번씩, 목록-상세 바뀜 2번, 동작 줄이기에서 이동 속성(transform·translate·scale·rotate)이 바뀌는 애니메이션 없음.
  움직임을 못 잡으면(잴 수단 고장) 실패. 일부러 깨 봄: 전파를 안 멈추면 3번 바뀜, 줄이기를 무시하는 애니메이션은 잡힘.
  UI 가 얼어 있어(Object.freeze) 문서가 생길 때 window.UI 를 대리자로 받아 transition 만 감싸 잰다.
- 브라우저 뒤로 가기(popstate)로 목록에 돌아오는 것은 키트가 바로 바꾼다(전환 없음) — 폰은 브라우저가 스와이프를 그린다.
