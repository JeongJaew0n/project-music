## 결정

- **키트 0.3.1 을 적용한다.** 사본은 `ytmp3/static/vendor/ui-kit/` (`adopt.mjs --to`). 서버가 `static/` 아래만
  내주므로 거기에 둔다. 서버의 `/static/` 은 하위 폴더(글꼴)도 내주게 고치되 `static/` 밖은 막는다.
- **화면을 셋으로 나눈다**(하단바·메뉴바 `UI.nav`, 주소 `#get`·`#songs`·`#cuts`): 받기 / 받은 곡(자르기) / 잘라낸 곡.
  받은 곡은 키트의 목록-상세 — 폰은 목록 → 편집기, 데스크톱은 나란히.
- 저장 폴더 바꾸기는 바텀시트(`UI.sheet`)로. 알림은 `UI.toast`.
- 파형은 캔버스라 키트 부품이 없다 — 색은 키트 토큰(`--ui-accent`·`--ui-t1`·`--ui-line`)을 읽어 그린다.
  테마가 바뀌면(`ui:theme`) 다시 그린다.
- 시험 모드 띠는 `ui-banner`.
- 진행 막대의 "정해지지 않은" 움직임은 동작 줄이기에서 멈춘다. 새 모션은 만들지 않는다(0.4 대기).
- 서버의 오류 문구(합니다체)는 이번에 바꾸지 않는다 — API 를 쓰는 AI·명령줄과 시험이 묶여 있다. 화면 문구만 해요체.
